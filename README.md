## 💡 How I Work with AI

- **역할을 나눈다**: 구현은 Claude Code, 리뷰는 Codex처럼 도구마다 역할을 정합니다.
- **권한의 경계를 먼저 정한다**: 하드웨어처럼 위험이 있는 작업에서는 AI가 하지 말아야 할 일을 규칙으로 먼저 적습니다.
- **지적은 재현한 뒤 고친다**: AI 리뷰 결과도 테스트로 재현해 확인한 뒤 수정합니다.
- **약점은 숨기지 않는다**: 낮은 성능이나 한계도 원인과 함께 공개합니다.
